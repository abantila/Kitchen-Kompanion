# Kitchen Kompanion

Kitchen Kompanion is a web application designed to help users manage kitchen inventory, plan meals, and generate shopping lists through an intuitive, user-centered interface. This project was developed as part of a Human-Computer Interaction (HCI) course.

## Overview

The goal of Kitchen Kompanion is to simplify kitchen organization by allowing users to keep track of ingredients, create meal plans, and generate shopping lists in one place.
